This project formulates maze navigation as a Markov decision process and implements reinforcement-learning algorithms for policy learning and path selection.

The code takes a maze image as input. The repository is public: [Maze-Solver-using-Markov-Decision-Processes](https://github.com/MoeMadadi/Maze-Solver-using-Markov-Decision-Processes).
